# Competitive Programming & Problem Solving 🚀

Welcome to my repository dedicated to algorithmic problem solving! Here, I maintain a clean, optimized, and structured collection of my solutions to various problems from popular competitive programming platforms.

## 🛠️ Languages Used
* **C++** (For high-performance & fast I/O in contests)
* **Python** (For rapid prototyping and clean algorithmic logic)

## 📌 Platforms Covered
* **Quera** (Including national contests like Technology Olympics)
* **Codeforces**
* **LeetCode**

## 📂 Repository Structure
The repository is organized by platform and contest/topic:
* `/Quera` - Solutions to Persian community contests and general question banks.
* `/Codeforces` - Div. 2, Div. 3, and global rounds.
* `/Algorithms` - Classic implementations (Graphs, Dynamic Programming, Greedy, etc.)

## 🎯 Featured Solutions
> Inside the folders, complex problems (like the **N-Queens Problem**) contain dedicated breakdowns explaining the **Time Complexity $O(f(n))$** and **Space Complexity** of the approach.
